# /test

Quick command to run the test suite.

## What it does

Executes `npm test` and reports results, helping verify that changes work correctly before committing.

## Usage

```
/test
```

The command will:
1. Run the full test suite
2. Show pass/fail status for each test
3. Report any errors or failures
4. Display total execution time

Use this before committing to ensure you haven't broken anything.
