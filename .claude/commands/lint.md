# /lint

Quick command to check code style.

## What it does

Executes `npm run lint` and reports style issues, helping catch code violations before committing.

## Usage

```
/lint
```

The command will:
1. Run ESLint across the codebase
2. Report any style violations
3. Suggest fixes where applicable
4. Exit with status 0 if all checks pass

Use this to ensure code meets the project's style standards.
